# Attribution

## Base project

This repository started as the completed project of GDQuest's free course
**"Your First 2D Game in Godot 4"** (Vampire Survivor style).

- Course: https://www.gdquest.com/library/first_2d_game_godot4_vampire_survivor/
- Source projects: https://github.com/gdquest-demos/getting-started-with-godot-4
- **Graphics, sprites and animations: © GDQuest, licensed CC BY 4.0**
  (https://creativecommons.org/licenses/by/4.0/)
- Tutorial code: adapted and extended for this workshop.

The sprites that come from GDQuest in this repository are: the player
character (HappyBoo), the slime enemy, the pistol, projectile, muzzle flash,
impact effect, the pine tree, ground shadow and the smoke explosion.
